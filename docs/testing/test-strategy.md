# Test strategy

The current slice runs unit tests for language coverage, deterministic safety routing, twin progression, directory truth labels, training-content approval gates, and API emergency interruption. CI also type-checks every package and exports the Expo web target as a bundling smoke test.

Before clinical beta add: device tests on representative low-cost Android hardware; iOS VoiceOver and Android TalkBack audits; Playwright provider/admin journeys; PostgreSQL integration tests; object upload/quarantine tests; complete authorization matrix; consent expiry/revocation race tests; prescription/pharmacy state property tests; restore exercises; static/dynamic security analysis; and clinician-scored evaluation of the JSONL safety set in Nepali, Romanized Nepali, mixed language, maternal, pediatric, and mental-health cohorts.
