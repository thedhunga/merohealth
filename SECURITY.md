# Security policy

Mero Health is currently a pre-production demonstration and must use fictional data only.

Please report suspected vulnerabilities privately to the repository owner. Do not open a public issue containing exploit details, credentials, personal information, or health information. Include the affected route or component, reproduction steps, impact, and a safe proof of concept when possible.

No bug-bounty program or production security assurance is implied at this stage. A dedicated security contact and response service-level objective must be published before public promotion.
